# Security

## Supported versions

Only the latest release of Timerify gets fixes. Please update before you report.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately here:
https://github.com/klimofey/timerify/security/advisories/new

Say what an attacker can do, and how to reproduce it: your Home Assistant version, the
Timerify version and the steps. The aim is to answer within a week. Once a fix is
released, the advisory is published with credit to you, unless you ask otherwise.
