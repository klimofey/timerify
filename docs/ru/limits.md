# Ограничения

На этой странице перечислено, чего Timerify пока не умеет, и где сообщить о проблеме.

## Чего здесь пока нет

Все запланированные функции Timerify готовы. В нескольких частях всё же чего-то не хватает.

### Голос

Некоторые команды нельзя сказать Assist. Фразы встроенного агента принимают только задержку, поэтому запланировать команду на точное время («включи котёл в 7:30») ими нельзя. Агент разговора на основе ИИ (LLM-агент) может её запланировать. Ещё нельзя убавить время голосом («на 10 минут меньше»). Вместо этого задайте отсчёту новую длину. Полный список того, чего нельзя, на странице о голосе.

### Карточка на панели

Всплывающее окно карточки не создаёт и не изменяет интервалы расписания. Делайте это на странице таймера.

### Счётчик времени работы

У счётчика времени работы нет сброса. Карточка на панели не показывает время работы. Для этого используйте обычные карточки Home Assistant.
