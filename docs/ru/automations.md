# Автоматизации

Timerify можно использовать в автоматизации без YAML. Вы выбираете устройство, затем действие Timerify.

## Выберите устройство

1. Откройте **Настройки > Автоматизации и сцены**. Нажмите **Создать автоматизацию**, затем **Создать новую автоматизацию**.
2. В разделе **Тогда** нажмите **Добавить действие**. Откройте вкладку **По назначению**.
3. Выберите устройство, например котёл.
4. В списке будут действия Timerify и остальные действия устройства. Выберите нужное.

Устройство, которое Timerify создал для объекта без устройства, работает так же.

Группа **Устройство** в том же окне не показывает действия Timerify. В ней только то, что предлагает собственная интеграция устройства, и действия его видов объектов, например установка значения **Включить на**. Этот список строит сам Home Assistant, поэтому действия Timerify лежат во вкладке **По назначению**.

## Действия

| Действие | Что делает |
| --- | --- |
| **Запустить** | Включает устройство на указанное число минут, не больше суток. |
| **Добавить время** | Сдвигает конец отсчёта, не больше суток в любую сторону. |
| **Остановить** | Завершает отсчёт и выключает устройство. Также выключает устройство, которое работает без отсчёта. |

Есть также **Добавить команду** и **Отменить команду**. Все поля описаны на странице [«Действия»](services.md).

Например, чтобы включить котёл на 20 минут, выберите **Запустить** и укажите в поле **Минуты** значение 20.

## Устройство с двумя таймерами

Допустим, у реле два канала, и у каждого свой таймер. Действие, направленное на устройство, работает с обоими таймерами. Чтобы направить его на один, замените цель на объект **Включить на** этого канала.
