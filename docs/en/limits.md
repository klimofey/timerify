# Limits

This page lists what Timerify does not do yet, and where to report a problem.

## What is not here yet

Every feature planned for Timerify is built. A few parts still leave some things out.

### Voice

Some things cannot be said to Assist. For example, you cannot take time off by voice ("10 minutes less"). Set the countdown to the new length instead. The [Voice page](voice.md#what-you-cannot-say) lists everything that is not possible.

### The dashboard card

The pop-up of the card does not create or edit schedule intervals. Do that on the timer's page.

### The runtime counter

The runtime counter has no reset. The dashboard card does not show the runtime. Use Home Assistant's own cards for it.

## Known faults and requests

Known faults and requests are listed as [GitHub issues](https://github.com/klimofey/timerify/issues).

One fault is worth knowing about before you start. On Home Assistant 2026.10, the dashboard card can be missing the first time a browser loads it. Refresh the page once. See [Known issue on Home Assistant 2026.10](card.md#known-issue-on-home-assistant-202610).
